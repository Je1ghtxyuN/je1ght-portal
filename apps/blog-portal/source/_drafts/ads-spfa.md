## SPFA算法流程

例：S→A→T 和 S→B→T，费用分别是 5+2=7 和 3+6=9

```
初始化：
dist = [0, ∞, ∞, ∞]    (S=0, A=1, B=2, T=3)
inq  = [T, F, F, F]
q = [S]
```

**步骤1：处理S**
```
弹出S，inq[S]=F
S的邻居：A(费用5)，B(费用3)
  → dist[A] = min(∞, 0+5) = 5，入队A  → q=[A], inq[A]=T
  → dist[B] = min(∞, 0+3) = 3，入队B  → q=[A,B], inq[B]=T
```

现在 `dist = [0, 5, 3, ∞]`，`q = [A, B]`

**步骤2：处理A**
```
弹出A，inq[A]=F
A的邻居：T(费用2)
  → dist[T] = min(∞, 5+2) = 7，入队T  → q=[B,T], inq[T]=T
```

现在 `dist = [0, 5, 3, 7]`，`q = [B, T]`

**步骤3：处理B**
```
弹出B，inq[B]=F
B的邻居：T(费用6)
  → dist[T] = min(7, 3+6) = 7，没有变小，不入队
```

现在 `dist = [0, 5, 3, 7]`，`q = [T]`

**步骤4：处理T**
```
弹出T，inq[T]=F
T没有邻居，什么都不做
```

**结束**：`q`为空，`dist[T]=7`，即最低费用7。

## 最小费用最大流
源自ads实验1038题

假设：男1喜欢{女1,女2}，男2喜欢{女1}，男3喜欢{女3}
费用：女1对男1=5，女1对男2=3，女2对男1=4，女3对男3=2

**第一轮SPFA（找从S到T的最便宜路径）**：

```
初始化：dist = [0, ∞, ∞, ∞, ∞, ∞, ∞, ∞, ∞]
inq[S]=T, q=[S]

弹出S(0)：遍历邻居{男1(1), 男2(2), 男3(3)}
  dist[1] = 0+0 = 0, q=[1], inq[1]=T
  dist[2] = 0+0 = 0, q=[1,2], inq[2]=T
  dist[3] = 0+0 = 0, q=[1,2,3], inq[3]=T

弹出男1(1)：遍历邻居{女1(4), 女2(5)}
  dist[4] = 0+5 = 5, q=[2,3,4], inq[4]=T
  dist[5] = 0+4 = 4, q=[2,3,4,5], inq[5]=T

弹出男2(2)：遍历邻居{女1(4)}
  dist[4] = min(5, 0+3) = 3!  ← 发现到女1更便宜的路了！
  parent[4] = 2  ← 记下来：女1是从男2走过来的
  inq[4]已经是T，不重复入队

弹出男3(3)：遍历邻居{女3(6)}
  dist[6] = 0+2 = 2, q=[4,5,6], inq[6]=T

弹出女1(4)：遍历邻居{T(8)}
  dist[8] = 3+0 = 3, q=[5,6,8], inq[8]=T  ← 找到到T的路了！

弹出女2(5)：遍历邻居{T(8)}
  dist[8] = min(3, 4+0) = 3, 没变小

弹出女3(6)：遍历邻居{T(8)}
  dist[8] = min(3, 2+0) = 2!  ← 更便宜！
  parent[8] = 6

弹出T(8)：没有邻居

结束！dist[8]=2，回溯路径：8←6←3←0
即 S → 男3 → 女3 → T，费用=0+2+0=2
```

**第一次增广**：男3配上女3，费用=2

---

**第二轮SPFA**：重复同样的过程，但因为男3→女3已经满流了，这条路走不通了，最终找到 S→男2→女1→T（费用3），或者 S→男1→女2→T（费用4）
